Why I built it

With an AI coding tool, “that button there, no, not like that” is hard to put into words. A screenshot with the problem circled gets a much more specific fix. But that meant capturing the screen, marking it up in Paint, saving it, pasting it into the AI window and typing out what each mark meant, every single time. I built Backseat to cut that work down.

The name comes from “backseat driver”: the AI is at the wheel writing the code while you sit behind it, pointing at the screen and talking. Explain things the way you would to an AI standing behind you, looking at the same monitor.

How it works

First, open the project you want to fix in your AI coding tool.

  1. 1Capture the screen

    On the screen you want fixed, press the hotkey and drag over the part to show. The editor opens right away.

    Region Ctrl+Shift+A · Window Ctrl+Shift+W

  2. 2Mark it up and explain

    Mark what to fix with arrows, numbers, a pen or text. Start recording and talk while you draw: each sentence is linked to the mark you were drawing at the time.

    You don't have to talk. Marks alone, or a one-line note, are enough to send.

    Record M · Backseat transcribes your speech on your PC.

  3. 3Hand it to your AI

    Press Send and Backseat tries to paste it into the input box of the AI window you used last. Check what went in, then submit it yourself in that window.

    Send Enter · What goes in depends on the target.

What it saves

Each fix used to take five steps by hand. With Backseat it's one shortcut, drawing while you talk, and Enter.

What you did by handWith Backseat
1. Capture the screen. Press Ctrl+Shift+A and drag. The editor opens right away.
2. Open Paint and mark it up. Draw right in the editor.
3. Save the image as a file. Backseat saves it on your PC when you send.
4. Switch to the AI window and paste the image. Press Enter and Backseat tries to paste into the AI window you used last.
5. Type out what to change at each mark. Talk while you draw. Each sentence is linked to the mark you were drawing.

If the paste doesn't go through, everything is on the clipboard: press Ctrl+V in the AI window. You still submit it yourself, as before.

Which AI tools does it work with?

By default, Send goes to the AI tool window you used last. To send somewhere else, click the target at the top right of the editor or press Ctrl+T.

More on what gets sent and where

What goes in?

  • Terminals and code editors get a request line plus the locations of the marked-up image and the request file. The AI tool has to be able to open files on your PC.
  • For chat apps and browser tabs, Backseat tries to paste the marked-up image and the request line, because a chat AI can't open files on your PC.
  • If you send without drawing or saying anything, only the image goes, with no request line. A terminal gets just the image's location.
  • An AI tool set up with MCP can fetch captures from Backseat directly. Everything else works without it. MCP setup

How is the target chosen?

  • Only an AI tool window you used recently is chosen automatically. The web page you just captured and messengers are never chosen automatically.
  • To send to a messenger or any other window, pick it from the list. If no target is set, nothing is pasted and everything stays on the clipboard.
  • Right before pasting, it checks the input box under the cursor. If Windows reports a password field, or it can't tell that it is an input box, it stops. It can't recognize a password prompt inside a terminal.
  • Under the editor you see only the steps it actually went through, such as saved, target checked and paste attempted. If it stopped, it tells you why and what to do next.

The sign-in page was picked by hand, but Backseat stops because the cursor is in a password field. Other window names in the list are blurred.

Install

Checked on 64-bit Windows 10. Windows 11 has not been tried yet.

  1. Download the installer

    Get Backseat.Setup.0.5.0.exe (about 243 MB) from the GitHub release page. Official builds are published only on this repository's releases.

  2. Run the installer

    The installer isn't code-signed yet, so “Windows protected your PC” may appear. It means Windows can't verify the publisher. If the file came from the release page above, click “More info”, then “Run anyway”.

  3. Find it in the notification area and start

    When this icon appears in the notification area at the right of the taskbar, it is ready. Hovering it shows “Backseat — Ctrl+Shift+A to capture”. If you don't see it, click ^ on the taskbar to show hidden icons.

    No big window opens, and that's normal. On the screen you want fixed, press Ctrl+Shift+A to start. Clicking the icon also starts a capture.

    The first time you record, Backseat downloads a speech recognition model of about 0.9 GB, once. If you never record, it isn't downloaded.

    Backseat starts when you sign in to Windows. To stop that, turn off “Start at login” in the icon's menu.

Check your download against the release

This checks that your file is the same file published on the release page. Run this in PowerShell:

Get-FileHash "$env:USERPROFILE\Downloads\Backseat.Setup.0.5.0.exe" -Algorithm SHA256

SHA-256 of v0.5.0: 8B5E1225237FCC0E57CDFCBFF7F0D4988248C9FF3E7FFAA5A8B1635BC17F033B

If the values match, you have exactly the published file. That does not prove the program is safe. If they differ, don't run it: download it again or report it.

macOS and Linux preview ◐ Preview

Capture, marking up, voice transcription, saving and MCP work as on Windows. Picking the destination, checking the input box and pasting are Windows-only, so in the preview Send puts everything on the clipboard: paste it into your AI window yourself with Cmd+V on macOS or Ctrl+V on Linux. Window capture and scrolling capture aren't available either.

  • macOS (Apple Silicon): Download the dmg (about 221 MB). Move the app to Applications. It isn't notarized by Apple, so if macOS blocks it the first time, click “Open Anyway” in System Settings → Privacy & Security. Allow Screen Recording on the first capture and the microphone on the first recording.
  • Linux (x64 AppImage): Download the AppImage (about 447 MB). Make it executable with chmod +x and run it. The tray icon may need AppIndicator support in your desktop, and global shortcuts may not work in a Wayland session.

How far it was checked: the packages passed automated checks of capture, the editor, the clipboard and saving on GitHub's macOS and Linux build machines. Not tried on a real Mac or Linux PC yet. Version v0.6.0-preview.1 · release page · report a problem.

FAQ

What does voice download the first time?

The first recording downloads the Whisper speech recognition model, about 0.9 GB, once. After that, Backseat transcribes speech on your PC. Audio goes to a cloud speech service only if you set one up. What Backseat pastes into an AI window is handled by that AI service.

The transcript is wrong. What can I do?

The transcribed text can't be edited in the editor. Instead:

  • If a word or two is wrong, type the correction in the one-line note at the bottom of the editor and send it along.
  • If much of it is wrong, press M and record again. The new recording replaces the old one and its transcript, and resets any links you changed.

The request file also tells the agent that the transcript is automatic, so numbers and names may be wrong.

A sentence is linked to the wrong mark

Press L to open the timeline and drag the sentence's bar in the voice lane onto the bar of the mark it belongs to. Drop it on empty space in the voice lane to go back to automatic linking.

Nothing was pasted

If it can't confirm the input box, it doesn't paste and leaves everything on the clipboard. Click the AI window's input box and press Ctrl+V. The reason it stopped is shown under the editor. This happens often in chat apps with several input boxes.

Why do I submit it myself?

By default Backseat pastes but does not submit, so you can check what went in first. If you turn on “Press Enter after sending” in the tray menu, Backseat presses Enter too, but only when both the target and the input box were confirmed.

What does “Paste attempted” in the editor mean?

It means the paste command was sent. Backseat can't tell whether the image and text actually went in, so check the AI window. When an AI tool connected with MCP fetches the capture, the editor shows “The AI fetched the capture” instead.

Where are captures kept?

Every send saves the marked-up image, the original screenshot, the request file, and any recording and transcript under Backseat\sessions in your Pictures folder.

Which operating systems are supported?

The full version is for Windows 64-bit and was checked on Windows 10; Windows 11 hasn't been tried yet. For macOS (Apple Silicon) and Linux (x64) there is a preview without automatic paste, not yet tried on a real Mac or Linux PC.
