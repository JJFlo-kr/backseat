How it works

First, open the project you want to fix in your AI coding tool.

  1. 1Capture the screen

    On the screen you want fixed, press the hotkey and drag over the part to show. The editor opens right away.

    Region Ctrl+Shift+A · Window Ctrl+Shift+W

  2. 2Mark it up and explain

    Mark what to fix with arrows, numbers, a pen or text. Start recording and talk while you draw: each sentence is paired with the mark you were drawing at the time.

    Voice is optional. You can send just a one-line note, or only the marks.

    Record M · Speech is turned into text on your PC.

  3. 3Hand it to your AI

    Press Send and Backseat pastes it into the input box of the AI window you used last. Check what went in, then submit it yourself in that window.

    Send Enter · What goes in depends on the destination.

More on what gets sent and where

What goes in?

  • Terminals and code editors get a request line with the file paths of the marked-up image and the request file (brief.md). The agent has to be able to read files on your PC.
  • Chat apps and browser tabs are designed to get the marked-up image and the request line, because a chat AI can't open files on your PC.
  • If you send without drawing or saying anything, only the image goes (only its path, for a terminal), with no request line.
  • An agent set up over MCP can fetch captures from Backseat itself. This is optional. MCP setup

How is the destination chosen?

  • Only an AI tool window you used recently is chosen automatically. The web page you just captured and messengers are never chosen automatically.
  • You can still send to a messenger or any other window by picking it from the list. If no destination is set, nothing is pasted and everything stays on the clipboard.
  • Right before pasting, it checks the input box under the cursor. If Windows reports a password field, or it can't tell that it is an input box, it stops. It can't recognize a password prompt inside a terminal.
  • Under the editor you see only the steps it actually went through: saved, on clipboard, destination checked, input box checked, paste command sent. If it stopped, it tells you why and what to do next.

The sign-in page was picked by hand, but Backseat stops because the cursor is in a password field. Other window names in the list are blurred.

Install

Checked on Windows 10 (64-bit). Windows 11 has not been tried yet.

  1. Download the installer

    Get Backseat.Setup.0.5.0.exe (about 243 MB) from the GitHub release page. Official builds are published only on this repository's releases.

  2. Run the installer

    The installer isn't code-signed yet, so “Windows protected your PC” may appear. It means Windows can't verify the publisher. If you got the file from the release page above and want to continue, click “More info”, then “Run anyway”.

  3. Find it in the notification area and start

    When this icon appears in the notification area at the right of the taskbar, it is ready. Hovering it shows “Backseat — Ctrl+Shift+A to capture”. If you don't see it, click ^ (show hidden icons) on the taskbar.

    No big window opens, and that's normal. On the screen you want fixed, press Ctrl+Shift+A to start. Clicking the icon also starts a capture.

    The first time you record your voice, it downloads a speech recognition model (about 0.9 GB) once. If you don't use voice, it isn't downloaded.

    It starts each time you sign in to Windows; you can turn that off with “Start at login” in the icon's menu.

How to verify the download (optional)

This checks that your file is the same file published on the release page. Run this in PowerShell:

Get-FileHash "$env:USERPROFILE\Downloads\Backseat.Setup.0.5.0.exe" -Algorithm SHA256

SHA-256 of v0.5.0: 8B5E1225237FCC0E57CDFCBFF7F0D4988248C9FF3E7FFAA5A8B1635BC17F033B

If the values match, you have exactly the published file. That does not prove the program is safe. If they differ, don't run it: download it again or report it.

FAQ

What does voice download the first time?

The first recording downloads a speech recognition model once (Whisper small, about 0.9 GB). After that, speech is turned into text on your PC. Audio goes to a cloud speech service only if you set one up. What Backseat pastes into an AI window is handled by that AI service.

The transcript is wrong. What can I do?

The transcribed text can't be edited in the editor. Instead:

  • If a word or two is wrong, type the correction in the one-line note at the bottom of the editor and send it along.
  • If much of it is wrong, record again (M). The new recording replaces the old one and its transcript, and resets any links you changed.

The request file also tells the agent that the transcript is automatic, so numbers and names may be wrong.

A sentence is linked to the wrong mark

Open the timeline (L) and drag the sentence's bar in the voice lane onto the bar of the mark it belongs to. Drop it on empty space in the voice lane to go back to automatic linking.

Nothing was pasted

If it can't confirm the input box, it doesn't paste and leaves everything on the clipboard. Click the AI window's input box and press Ctrl+V. The reason it stopped is shown under the editor. This happens often in apps with several input boxes, such as the Claude and ChatGPT desktop apps.

Why do I submit it myself?

By default Backseat pastes but does not submit, so you can check what went in first. You can turn on “Press Enter after sending” in the tray menu, but it only presses Enter when both the destination and the input box were confirmed.

What does “Paste attempted” in the editor mean?

It means the paste command was sent. Backseat can't tell whether the image and text actually went in, so check the AI window. When an agent connected over MCP fetches the capture, the editor says “The AI fetched the capture” instead.

Where are captures kept?

Every send saves the marked-up image, the original screenshot, the request file (brief.md), and any recording and transcript under Backseat\sessions in your Pictures folder.

Which operating systems are supported?

Windows 64-bit only. It was checked on Windows 10; Windows 11 hasn't been tried yet. macOS and Linux aren't supported.
