Backseat

Mark up your screen, explain it out loud, and pass it on to your AI.

Capture your screen, draw on it while you talk, and send it to your AI coding agent. Free, open source (MIT), for Windows.

Download for Windows (v0.5.0) View on GitHub

Windows only. The installer is not code-signed yet, so Windows SmartScreen may warn the first time: choose "More info", then "Run anyway".

How it works

Three steps, all from the keyboard.

  1. 1Capture & mark

    Press Ctrl+Shift+A and drag over the part of the screen you mean. Then add arrows, numbers, pen strokes, boxes or text.

  2. 2Talk while you draw

    Press M and say what you want. Each sentence is tied to the mark you were drawing at that moment.

    Speech is transcribed on your PC with Whisper (the speech model downloads on first use). Automatic transcripts can be wrong, so check the timeline.

  3. 3Send to the AI window you were using

    Press Enter. Backseat saves a brief and the images, then tries to paste them into the input box of the AI window you used last. You check it and press Enter there.

Safe by default

Pasting into the wrong place is the easy mistake. Backseat is built to avoid it.

  • It does not paste into unknown windows, messengers or password fields. Your capture goes to the AI window you used last, not to the page you captured. A messenger or other window only gets it if you pick it yourself. If the cursor is in a password field, nothing is pasted, even when you chose that window.
  • It shows only the delivery steps it could confirm. Saved, copied, target found, input box found. A paste is shown as "attempted", never as "received".
  • You press Enter yourself. By default Backseat pastes but does not submit. You read it first, then send it.

Send it to the AI you already use

Backseat pastes into the input box of the window you were using. These are the places it sends to:

  • Claude Code
  • Codex CLI / ChatGPT app
  • Claude app
  • Cursor
  • VS Code
  • Browser AI tabs

Apps with several input boxes, such as the Claude and ChatGPT desktop apps, may stop at "ready on the clipboard". Click the input box and press Ctrl+V. Terminals usually paste straight in.

Demo videos are real recordings of the app driven by a script; the voice is text-to-speech. Music: “Corporate company introduction video” by Bertsz (CC0).

Backseat is free, and every feature is included. It runs on Windows only. It is open source under the MIT licence.
