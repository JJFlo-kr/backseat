**Preview for macOS (Apple Silicon) and Linux (x64).** Windows users: keep using [v0.5.0](https://github.com/JJFlo-kr/backseat/releases/tag/v0.5.0); this preview changes nothing for Windows.

## What works

Capture a region (`Cmd+Shift+A` on macOS, `Ctrl+Shift+A` on Linux), mark it up, talk while you draw (speech is transcribed on your computer), save the session, and let an agent fetch it over MCP. These are the same as on Windows.

## What is different from Windows

- **No automatic paste.** Picking the destination window, checking its input box and pasting are Windows-only. Send puts the marked-up image and the request line on the clipboard and says so; paste it in your AI window yourself (`Cmd+V` / `Ctrl+V`).
- No window capture and no scrolling capture.
- No "Press Enter after sending" and no "Send to" menu. On Linux there is no "Start at login" option.

## Installing

- **macOS:** open the `.dmg` and drag Backseat to Applications (or unzip the `.zip`). The app is ad-hoc signed and not notarized by Apple: if macOS says it can't be opened, click "Open Anyway" in System Settings → Privacy & Security. Allow Screen Recording when you first capture (then quit and reopen Backseat) and the microphone when you first record. Backseat lives in the menu bar, with no Dock icon.
- **Linux:** `chmod +x Backseat-*.AppImage`, then run it. The tray icon may need AppIndicator support in your desktop, and global shortcuts may not work in a Wayland session; clicking the tray icon also starts a capture.

The first recording downloads the speech model (about 0.9 GB) once.

## How far this was checked

The packaged apps pass Backseat's self-test (capture, region crop, editor, clipboard, session save) on GitHub's macOS and Linux build machines. **They have not been tried on a real Mac or Linux PC yet.** Please [report problems](https://github.com/JJFlo-kr/backseat/issues).

Check a download against `SHA256SUMS.txt` (for example `shasum -a 256 -c SHA256SUMS.txt` on macOS, `sha256sum -c SHA256SUMS.txt` on Linux). A matching value means you have the published file; it does not prove the program is safe.
